# Transcripts

Each episode page shows the transcript in `data/transcripts/<slug>.txt`, where `<slug>` is the
last part of the episode's URL (antifirm.com/episodes/<slug>/). Paste Riverside's transcript as is:

```
Jordan Teague (0:02.626)
What they said.

George Campbell (0:09.806)
What they said next.
```

The times become buttons that jump the player to that moment. Episodes without a file say the
transcript isn't up yet.
